<div align="center"> <strong>Status:</strong> ✅ Solved <br> <strong>Difficulty:</strong> 🟡Medium <br> <strong>Topics:</strong> String, Sliding Window, Hash Table <br> </div>

📝 Problem Description
> Given a string s, find the length of the longest substring without duplicate characters.

✔️ The substring must be continuous, not just a subsequence. <br>✔️ The input string may contain letters, digits, symbols, and spaces.

📌 Test Cases:
```C++
# Example 1:
Input: s = "abcabcbb"
Output: 3

# Example 2:
Input: s = "bbbbb"
Output: 1

# Example 3:
Input: s = "pwwkew"
Output: 3
