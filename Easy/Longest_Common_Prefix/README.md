📝 Problem Description
> Write a function to find the longest common prefix string amongst an array of strings.

✔️ The prefix must be continuous, starting from the first character. <br>
✔️ If there is no common prefix, return an empty string `""`. <br>
✔️ Strings consist of lowercase English letters.

📌 Test Cases:
```C++
# Example 1:
Input: strs = ["flower", "flow", "flight"]
Output: "fl"

# Example 2:
Input: strs = ["dog", "racecar", "car"]
Output: ""
Explanation: There is no common prefix among the input strings.
