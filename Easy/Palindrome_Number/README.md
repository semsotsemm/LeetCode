### 📝 Problem Description
> Given an integer `x`, return `true` if `x` is a palindrome, and `false` otherwise.

✔️ A number is a palindrome if it reads the same forwards and backwards.  
✔️ Negative numbers **cannot** be palindromes.  
✔️ The number should be checked without converting it into a string.  

---

```C++
# Example 1:
Input: x = 121
Output: true

# Example 2:
Input: x = -121
Output: false

# Example 3:
Input: x = 10
Output: false
